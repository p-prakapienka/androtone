# Riffbook product spec

Riffbook is an Android sketchpad for musical ideas. It is a clean-room reimplementation of the
workflow of Ableton Note (iOS). This file is the canonical description of what the app does:
every feature should trace back to a requirement ID here (`SET-1`, `CLIP-3`, ...).

Working name: **Riffbook** (rename freely; nothing depends on it).

## Ground rules

- Built from observed behaviour and the public Note reference manual only. No decompiling, no
  Ableton assets, names, icons or presets. The manual is not stored in this repo.
- All factory sounds are generated by our own code (synthesised drum hits, rendered instrument
  tones) or recorded by us, so there is nothing to license.
- Device names are our own: **Analog** (subtractive synth), **Wave** (wavetable synth),
  **Drum Kit** (16-pad rack of **Pad Samplers**), **Sampler** (melodic sampler).
- iOS/Ableton-only services are replaced with Android equivalents (see "Out of scope").

## 1. Set library (`LIB`)

| ID | Requirement |
| --- | --- |
| LIB-1 | The app opens on a library listing the user's sets (newest first) and demo sets. |
| LIB-2 | "+ New" creates a set with three tracks, each loaded with a random preset: one drum, one bass, one melodic or sampler preset. Opens it in the session view. |
| LIB-3 | Each set row has a play button that previews the set from the library (plays scenes from the top). |
| LIB-4 | Set options: duplicate, rename, delete, share. Share writes a single bundle file (set + samples) and hands it to the Android share sheet. Bundles can be opened again by Riffbook. |
| LIB-5 | Sets save automatically on every change. Nothing is lost on app close or crash. |
| LIB-6 | App settings are reachable from the library (see §11). |

## 2. Session view (`SES`)

| ID | Requirement |
| --- | --- |
| SES-1 | Shows a grid: tracks are columns (header at the top), scenes are rows of clip slots. |
| SES-2 | A back arrow returns to the library; a set-settings button opens §3. |
| SES-3 | Bottom bar: undo, redo, show/hide mixer, show/hide scene numbers, global play/stop. |

### Tracks (`TRK`)

| ID | Requirement |
| --- | --- |
| TRK-1 | A set has 1–8 tracks. An "add track" button follows the last track while there are fewer than 8. |
| TRK-2 | Long-press a track header: drag to reorder, or Duplicate / Delete. |
| TRK-3 | Tapping a track header opens the instrument view for that track. |

### Clips (`CLIP`)

| ID | Requirement |
| --- | --- |
| CLIP-1 | An empty slot shows an "add clip" affordance. Tapping it opens the instrument view ready to create a clip in that slot. |
| CLIP-2 | Tapping a clip launches it at the next downbeat (bar boundary). If the transport is stopped, it starts the transport. One clip plays per track. |
| CLIP-3 | A playing clip shows a stop button; stopping takes effect at the next downbeat. |
| CLIP-4 | Long-press a clip: drag to any slot on any track; or Edit, Duplicate, Delete. |
| CLIP-5 | Double-tapping a clip opens it in the instrument view. |
| CLIP-6 | Clip length is 1–16 bars of 4/4. A clip has a loop region inside its length (see EDIT-12). |

### Scenes (`SCN`)

| ID | Requirement |
| --- | --- |
| SCN-1 | Up to 8 scenes. A scene is one row of slots across all tracks. |
| SCN-2 | Scene numbers can be shown or hidden. Tapping a number launches every clip in the row at the next downbeat; tracks with an empty slot in that row stop. |
| SCN-3 | Long-press a scene number: drag to reorder, Duplicate, Delete. |

### Mixer (`MIX`)

| ID | Requirement |
| --- | --- |
| MIX-1 | Toggled from the bottom bar; shows per-track volume slider, mute (M) and solo (S). |
| MIX-2 | Solo on any track silences every track that is not soloed. |

## 3. Set settings (`SET`)

| ID | Requirement |
| --- | --- |
| SET-1 | Tempo: coarse slider, −1/+1 BPM buttons, tap tempo (tempo set after 4 taps, then follows further taps). Range 20–999 BPM, default 120. |
| SET-2 | Metronome on/off. When on, it clicks while the transport runs (accented downbeat). |
| SET-3 | Key & scale: "In Key" switch (off by default = chromatic), root note, scale type. Includes preview pads that play the last-selected melodic instrument. Disabled when no melodic track exists. |
| SET-4 | Export audio (disabled when the set has no clips) — see §10. |

## 4. Instrument view (`INS`)

| ID | Requirement |
| --- | --- |
| INS-1 | Opened from a clip (double-tap), a track header, or an empty slot (which creates the clip). Back arrow returns to the session view. |
| INS-2 | Layout, top to bottom: preset name; preset section (tabs); clip preview / MIDI editor; pads; action bar. |
| INS-3 | Action bar: undo/redo, pad performance options, duplicate clip, quantize, play/stop, and the capture controls (§6). |
| INS-4 | Duplicate clip copies the open clip into the next free slot of the track and switches playback to the copy seamlessly. |
| INS-5 | Quantize (tap) quantizes all notes of the open clip with the current quantize settings; long-press opens the quantization tab. |

## 5. Devices, presets and effects (`DEV`)

### Track presets

| ID | Requirement |
| --- | --- |
| DEV-1 | A track preset = one instrument + two audio effects + parameter values. The preset name is shown at the top of the instrument view, with `*` when modified. |
| DEV-2 | Instruments: **Analog**, **Drum Kit**, **Sampler**, **Wave** — each with its own icon. |
| DEV-3 | Browser: categories (Drums, Bass, Keys, Lead, Pad, Pluck, Mallets, Sampler, FX…), search, filter by type, favorites (heart), preview on tap, pads under the list to audition, Done to load. |
| DEV-4 | User presets: save the current state to the user library (organised by instrument category). |

### Parameters

| ID | Requirement |
| --- | --- |
| DEV-10 | Knobs: drag up/down (or left/right) to change; double-tap resets to default; single tap opens options: reset, insert automation, delete automation. |
| DEV-11 | **Analog** tabs: Macros (up to 8 preset-chosen parameters), Osc, Filter, Env, LFO, Mod, Global. All tabs are available (no paywall). LFOs run free in Hz or sync to the tempo (4 bars .. 1/32, with triplets); the same applies to Wave. |
| DEV-12 | **Drum Kit** (per selected pad), page 1: Transpose (semitones), Filter type (LP12, LP24, HP24, Peak) with cutoff and resonance/gain on an XY display, Detune (cents), Attack, Hold (with Trig/Gate mode), Decay. |
| DEV-13 | **Drum Kit** page 2: Pan; FX type (Stretch, Loop, Pitch Env, Punch, 8-Bit, FM, Ring Mod, Sub Osc, Noise) with two FX parameters on an XY pad; Velocity → target (Filter, Attack, Hold, Decay, FX1, FX2); Velocity → Volume. |
| DEV-14 | **Sampler**: Filter freq with type (LP, BP, HP), Transpose, Detune, Attack, Decay (Trig/Gate), Release, Filter LFO amount. |
| DEV-15 | **Wave**: two wavetable oscillators with position, filter, envelopes, LFO; the first tab shows the preset's macro parameters. |

### Effects

| ID | Requirement |
| --- | --- |
| DEV-20 | Each track has two effect slots (tabs). For Analog/Sampler/Wave they are FX1 → FX2 in series. |
| DEV-21 | For a Drum Kit they are **Pad FX** (a send effect; each pad has its own Send Amount) and **Kit FX** (insert on the whole kit). |
| DEV-22 | Effect types: Auto Filter (LFO + envelope follower), EQ (3-band channel EQ), Chorus (Chorus / Ensemble / Vibrato), Delay (time, feedback, filter, modulation), Dynamics (compressor + EQ), Phaser (Doubler / Flanger / Phaser), Crusher (bit/rate reduction, jitter, filter), Reverb, Saturator (several curves, colour). |
| DEV-23 | Effects have presets in the browser and can be favorited. |

### Automation

| ID | Requirement |
| --- | --- |
| DEV-30 | While the transport runs, moving a parameter records a pending (dotted) automation line in the clip preview. |
| DEV-31 | "Add" commits pending automation for all touched parameters into the clip (solid line); automated parameters show a dot and follow the automation on playback. |
| DEV-32 | Parameter options: Insert (flat line at current value), Delete (remove automation). Reset is disabled while automated. |

## 6. Playing and capturing (`CAP`)

### Pads

| ID | Requirement |
| --- | --- |
| PAD-1 | Drum Kit: 4×4 velocity-sensitive pads (velocity from touch position or pressure). Tapping a pad also selects it for editing. |
| PAD-2 | Drum Kit "Single" layout: one large pad for the selected drum; higher on the pad = higher velocity. |
| PAD-3 | Melodic: 5×5 pads in Fourths (each row +5 semitones) or Sequential layout (app setting), root at bottom-left. Root notes are highlighted. |
| PAD-4 | Melodic "Keys" layout: two-octave keyboard. With In Key on it is a row of equal keys (scale notes only); off, a piano keyboard. |
| PAD-5 | In Key on: pads only contain notes of the set's scale. |
| PAD-6 | Octave up/down for melodic pads and keys. |
| PAD-7 | Repeat: off or 1/4, 1/8, 1/16, 1/32 (plus triplets). While a pad is held it retriggers at that rate, locked to the transport grid. |
| PAD-8 | Pad performance options (layout, octave, repeat) are stored per track in the set. |

### Capture

| ID | Requirement |
| --- | --- |
| CAP-1 | Everything played on the pads is recorded into a per-track capture buffer, whether or not anything is armed. |
| CAP-2 | **Fixed length:** the "+" in an empty clip area offers 1, 2, 4, 8 or 16 bars. The new clip loops; played notes appear in the editor as pending; **Add** commits them into the clip. |
| CAP-3 | **Free length, transport stopped:** play up to 8 bars, then **Capture** creates a clip from the performance. If this is the first clip in the set, the tempo is estimated from the performance. |
| CAP-4 | **Free length, transport running:** **Create Clip** creates a clip from the buffered notes, at least as many bars as the shortest clip in the set, aligned to the bar grid. |
| CAP-5 | With a clip playing, notes played and then **Add**-ed are overdubbed into that clip. |
| CAP-6 | An X next to Capture clears the buffer. |
| CAP-7 | Capture timeout (app setting, default on): the uncaptured buffer clears after a short pause in playing. Off: it clears only when playing starts again after no capture. Does not affect overdub. |

## 7. MIDI editor (`EDIT`)

| ID | Requirement |
| --- | --- |
| EDIT-1 | The clip preview shows the clip's notes; long-press offers duplicate loop, crop, delete, or create clip. Tapping it opens the editor. |
| EDIT-2 | The editor has a time ruler, loop brace and a grid of rows (drum pads or pitches) by columns (time). Inline it shows only rows that have notes (or the selected pad/key); expanded (full screen) it shows every pad or the full key range. The expand button can be moved to any corner. |
| EDIT-3 | Expanded mode has undo/redo, the note-edit menu button, duplicate loop and a triplet-grid toggle. Works in landscape. |
| EDIT-4 | Pinch to zoom horizontally; swipe to scroll. |
| EDIT-5 | Tap an empty cell to add a note one cell long (melodic: same length as the last drawn note). Tap a note to delete it. |
| EDIT-6 | Press-and-hold then drag draws: drum rows get consecutive notes, melodic rows get one note whose length follows the drag. |
| EDIT-7 | Drag a note's right edge to change its length. |
| EDIT-8 | Long-press a note to select it; drag to extend the selection; press-hold on empty space and drag for a selection box; tap more notes to add them. Tapping outside clears. |
| EDIT-9 | Selected notes: drag from the left edge or centre to move in time / transpose; drag the right edge to resize; drag the velocity handle to change velocity. Velocity shows as colour saturation. |
| EDIT-10 | Note-edit menu tabs: **Operations** (grid value incl. off and triplets; shorten, nudge left, delete, nudge right, extend), **Transpose** (±1 step — scale steps when In Key; ±octave, disabled for drums; drum notes move between pads), **Quantization** (grid value, triplets, off = restore original timing, amount), **Velocity** (per-note sliders; swipe to draw; two-finger ramp), **Pitches** (drum clips only: per-hit pitch offset sliders). |
| EDIT-11 | The editor state (open/expanded) is remembered when leaving and returning to the instrument view. |
| EDIT-12 | Loop brace: drag edges to resize the loop; tap bars inside to add/remove them; long-press offers Duplicate and Delete (clip) when loop = clip, or Zoom to Loop, Crop and Delete (loop content only) when shorter; Zoom to Clip. Swipe up/down on the brace zooms to loop / clip. |

## 8. Samples (`SMP`)

| ID | Requirement |
| --- | --- |
| SMP-1 | Import WAV, AIFF and M4A (converted to WAV) through the Android share sheet / file picker. |
| SMP-2 | Drum Kit pads and the Sampler have a Sample tab with a waveform. Load Sample offers: imported files, saved recordings, factory library, other recordings in the current set. |
| SMP-3 | Record Sample records from the microphone into the selected pad / sampler; stop with the stop button or by tapping the red pad; tapping another pad starts recording into that one. |
| SMP-4 | Recordings are trimmed to the first transient. Drag the waveform horizontally to move the start point; vertically for gain (+24 to −70 dB); pinch to zoom. |
| SMP-5 | Long-pressing the record button switches the source between Microphone and Resample Output (records the app's own output). |
| SMP-6 | Sample options — Drum Kit: Choke (one choke group per kit), Mode (Trigger/Gate), Save Sample (recordings only), Swap Sample. Sampler: Mode, Save, Swap. |
| SMP-7 | The Sampler plays the sample at its original pitch on C3 and repitches it elsewhere. |
| SMP-8 | With "monitor input" on (app setting) and headphones connected, the input is audible while recording. |

## 9. MIDI input (`MIDI`)

| ID | Requirement |
| --- | --- |
| MIDI-1 | USB and Bluetooth MIDI devices are listed with enable toggles; enabled devices are remembered. |
| MIDI-2 | Incoming notes play the track open in the instrument view (or the selected track) and feed the capture buffer like the pads. Pitch bend bends the active track by ±2 semitones; poly aftertouch and channel pressure open the filter of Analog, Wave and Sampler by up to two octaves. |
| MIDI-3 | MIDI mapping: up to 8 macro knobs, plus Capture, Clear Capture, Start/Stop, Quantize, Undo, Redo, by "tap the target, then move the control". |

## 10. Export (`EXP`)

| ID | Requirement |
| --- | --- |
| EXP-1 | Export renders all scenes in order, top to bottom. Each scene lasts as long as its longest clip. |
| EXP-2 | Formats: WAV 48 kHz / 16-bit, or compressed FLAC 48 kHz (JUCE has no AAC encoder on Android; M4A could be added later through MediaCodec). |
| EXP-3 | Rendering shows progress, then a preview player with Share and Cancel. |

## 11. App settings (`APP`)

| ID | Requirement |
| --- | --- |
| APP-1 | MIDI input and mapping (§9). |
| APP-2 | Theme: Dark or High Contrast. |
| APP-3 | Capture timeout (CAP-7). |
| APP-4 | Show note names / show sample names on pads. |
| APP-5 | Melodic pad layout: Fourths or Sequential. |
| APP-6 | Show touches (draws a circle under each touch, for screen recordings). |
| APP-7 | Monitor audio input (SMP-8). |
| APP-8 | About: version, licences. |

## 12. Global (`GLB`)

| ID | Requirement |
| --- | --- |
| GLB-1 | Undo/redo covers every change to the set (notes, clips, tracks, scenes, parameters, mixer, settings). |
| GLB-2 | Audio keeps running while switching views. Low-latency output (AAudio via Oboe-class settings in JUCE). |
| GLB-3 | Microphone permission is requested the first time recording is needed. |

## Out of scope (for now)

- Ableton Cloud, Live/Move/Push transfer and `.ablbundle` — replaced by our own bundle + share sheet (LIB-4).
- Ableton Link — the SDK is GPL-2.0+ or needs a commercial licence; decide before adding.
- In-app purchase, reviews, Discord, Live Lite links.
- Audio tracks, warp markers, time signatures other than 4/4 (Note 2.x features not in the
  manual we work from).
